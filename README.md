# 人格修养 Skill（玉不琢不成器）

一个基于实证心理学的**个人成长教练技能**，为 AI 助手（WorkBuddy / Claude Code / 任意支持 SKILL.md 规范的智能体）设计的完整人格修养教练系统。

## 它解决什么问题

想改变自己的人（拖延、自控力差、自卑、状态低迷）最常见的失败路径是：

```
立志 → 热血 → 断崖式放弃 → 自责 → 更不敢再定目标
```

这个 skill 用实证心理学方法替换掉这个循环。核心立场：**问题从来不是「懒」，是回避循环 + 启动障碍**——这两样都有成熟解法。

## 方法论（全部有研究背书）

| 工具 | 原理 | 一句话版本 |
|------|------|-----------|
| 行为激活（BA） | 情绪跟随行为，不是反过来 | 先动 5 分钟，动力自然会来 |
| 自我关怀（Neff） | 自责与拖延正相关；自我关怀提高失败后的再尝试率 | 对自己用对朋友的标准 |
| 认知重构（CBT） | 情绪来自中间的自动思维，不是事件本身 | 「今天废了」≠「我废了」 |
| 习惯科学 | 意志力对抗算法没有胜算 | 物理隔离，不拼意志力 |
| 睡眠优先 | 连续两周睡 6 小时，脑力表现≈两天没睡 | 「懒」先查睡眠再谈意志 |

## 四种工作场景

- **场景 A · 打卡汇报**：只记录不评判；完成→具体肯定，未完成→「中断不算失败，明天直接回打卡表」
- **场景 B · 情绪低谷**：当场打断自责循环，拆掉全或无思维，给一个 5 分钟最小动作
- **场景 C · 具体求助**：求职/学技能/债务/社交，按证据等级引用决策指南
- **场景 D · 定期复盘**：数据化小结，和用户协商调难度

## 教练禁令（skill 内置）

- ❌ 「你就是太懒/想太多/不够狠」——归因于人格 = 重放失败剧本
- ❌ 「别人比你惨都行」——比惨式激励只会加深自卑
- ❌ 一次给 10 条建议——认知过载 = 新的回避理由
- ❌ 「加油！你一定可以！」——空洞鸡血，用户试过没用
- ❌ 推荐炒币/高杠杆搞钱——目标是止血和复利，不是赌

## 心理危机协议（最高优先级）

出现持续两周以上的「活着没意思」类念头 → 立即停止教练模式，给出心理援助热线（中国大陆：**12356**），建议就医。不分析动机、不做劝导式说教。
